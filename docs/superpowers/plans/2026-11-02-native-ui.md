# Windows 原生界面实施计划

**目标：** 用 Windows 原生控件取代 WebView，并继续使用已有的仓库状态和凭据。

**架构：** Go 监控服务与 JSON 存储保持不变；Windows 界面直接调用服务，使用原生列表、对话框、托盘和通知。启动时避免与旧版同时写入同一数据文件。

**技术：** Go、Walk/Win32、Windows 凭据管理器。

- [x] 覆盖仓库链接解析和标签筛选的行为测试。
- [x] 实现原生窗口、仓库列表、详情、标签筛选以及添加、标签、令牌和移除操作。
- [x] 接入托盘、后台刷新、通知、窗口置顶和单实例保护，保留旧数据迁移安全边界。
- [x] 测试完整套件并构建，在隔离数据目录中验证真实 Windows 界面，再确认原有仓库可读取。
